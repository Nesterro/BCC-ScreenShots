# 📷 BCC ScreenShot Studio

![BCC ScreenShot Studio Logo](app_icon.png)

**BCC ScreenShot Studio** — нативное десктопное приложение для Windows (.NET 10 / WPF) в лаконичном стиле **Mexican Red**, предназначенное для мгновенного захвата экрана, создания вырезок и векторных аннотаций (стрелки, рамки, текст, цензура, нумерованные шаги).

## 🚀 Как запустить приложение на ДРУГОМ компьютере

Вы можете перенести и запустить программу на любом другом компьютере с **Windows 10** или **Windows 11**. Существует 3 удобных способа:

### 🔹 Способ 1. Готовый запуск без установки дополнительных программ (Рекомендуемый)

1. **Скачайте папку с приложением**:
   - Зайдите в репозиторий [https://github.com/Nesterro/BCC-ScreenShots](https://github.com/Nesterro/BCC-ScreenShots).
   - Нажмите зеленую кнопку **`<Code>`** -> **`Download ZIP`** и распакуйте архив на другом ПК.
   - *Или скопируйте папку `BuildRelease` на флешку или отправьте архивом.*
2. **Запустите программу**:
   - Перейдите в папку `BuildRelease`.
   - Дважды кликните по файлу **`BCCScreenShot.exe`**.
   - Программа откроется моментально!

---

### 🔹 Способ 2. Запуск через закрепление на рабочем столе

1. Скопируйте папку `BuildRelease` в удобное место на другом ПК (например, `C:\Program Files\BCC ScreenShot` или `C:\Users\Имя\Documents\BCC ScreenShot`).
2. Нажмите правой кнопкой мыши по файлу `BCCScreenShot.exe` -> **`Отправить`** -> **`Рабочий стол (создать ярлык)`**.
3. Теперь вы можете запускать программу прямо с рабочего стола или закрепить её на панели задач Windows.

---

### 🔹 Способ 3. Сборка из исходных исходных кодов (Для разработчиков)

Если на другом ПК установлен **.NET SDK 10**:

1. Откройте терминал (PowerShell / Командная строка) на другом ПК.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Nesterro/BCC-ScreenShots.git
   cd BCC-ScreenShots
   ```
3. Скомпилируйте и запустите:
   ```bash
   dotnet run
   ```

## 🌟 Основные возможности

### 📸 Захват экрана
- **✂️ Захват рамкой (Region Snippet)**: Выделение любой области экрана зажатием кнопки мыши.
- **📸 Весь экран**: Снимок всех мониторов.
- **📁 Импорт**: Загрузка картинок PNG, JPG, BMP.

### 🎨 Инструменты аннотаций
- **↗️ Стрелки (`A`)**: Точные векторные указки.
- **🔲 Рамки (`R`) / ⭕ Овалы (`E`) / 📏 Линии (`L`)**: Выделение ключевых объектов.
- **🔤 Текст (`T`)**: Двойной клик по тексту открывает редактирование прямо на холсте.
- **🔢 Метки (`N`)**: Нумерованные кружки `1`, `2`, `3`... для инструкций.
- **💧 Размытие (`B`)**: Пикселизация цензуры личных данных.
- **↖ Перемещение & Сброс (`Esc`)**: Зажмите ЛКМ для движения элементов; нажмите `Esc` для отмены инструмента.

### 📋 Копирование и Сохранение
- **В буфер (`Ctrl + C`)**: Копирование в буфер Windows для вставки в Telegram, WhatsApp, Word или в письмо.
- **Сохранить PNG (`Ctrl + S`)**: Сохранение файла на диск.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Esc` | Сброс инструмента на режим выбора («↖ Выбор») |
| `Delete` / `Backspace` | Мгновенное удаление выделенного элемента |
| `Двойной клик по тексту` | Редактирование текста по месту |
| `Ctrl + C` | Скопировать изображение в буфер обмена Windows |
| `Ctrl + S` | Сохранить скриншот как PNG |
| `Ctrl + Z` | Отменить последнее действие |
