# 📷 BCC ScreenShot Studio

![BCC ScreenShot Studio Logo](app_icon.png)

**BCC ScreenShot Studio** — нативное десктопное приложение для Windows (.NET 10 / WPF) в лаконичном стиле **Mexican Red**, предназначенное для мгновенного захвата экрана, создания вырезок и векторных аннотаций (стрелки, рамки, текст, цензура, нумерованные шаги).

## 🌟 Основные возможности

### 📸 Захват экрана
- **✂️ Захват рамкой (Region Snippet)**: Выделение любой области экрана зажатием кнопки мыши.
- **📸 Весь экран**: Снимок всех мониторов.
- **📁 Импорт**: Загрузка картинок PNG, JPG, BMP.

### 🎨 Инструменты аннотаций
- **↗️ Стрелки (`A`)**: Точные векторные указки со строгой острой геометрией.
- **💬 Выноски (`C`)**: Текстовые карточки с интерактивным перетаскиванием точки-указателя.
- **🔲 Рамки (`R`) / ⭕ Овалы (`E`)**: Выделение объектов с затененным полупрозрачным фоном.
- **🔤 Текст (`T`)**: Многострочный текст с мгновенным редактированием по месту.
- **1️⃣ Метки (`N`)**: Нумерованные кружки (`1.1`, `A`, `Шаг 1`) с редактированием по двойному клику.
- **✏️ Карандаш (`P`) & 🖍️ Маркер (`H`)**: Произвольное рисование и полупрозрачная подсветка.
- **↖ Перемещение & Сброс (`Esc`)**: Перемещение элементов; `Esc` для отмены инструмента.

### 📋 Управление, Масштабирование и Копирование
- **🔍 Масштабирование холста (`Ctrl + Колесико мыши`, `Ctrl + 0`)**: Плавный зум от 20% до 400%.
- **📋 Дублирование элементов (`Ctrl + Перетаскивание мышью`)**: Мгновенное копирование любых объектов.
- **В буфер (`Ctrl + C`)**: Копирование в буфер Windows для вставки в Telegram, WhatsApp, Word или в письмо.
- **Сохранить PNG (`Ctrl + S`)**: Сохранение файла на диск.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + Колесико` | Масштабирование холста |
| `Ctrl + 0` | Сброс масштаба на 100% |
| `Ctrl + Drag` | Дублировать / скопировать элемент |
| `Esc` | Сброс инструмента на режим выбора («↖ Выбор») |
| `Delete` / `Backspace` | Мгновенное удаление выделенного элемента |
| `Двойной клик по тексту/метке` | Редактирование содержимого по месту |
| `Ctrl + C` | Скопировать изображение в системный буфер обмена Windows |
| `Ctrl + S` | Сохранить скриншот как PNG |
| `Ctrl + Z` | Отменить последнее действие |
