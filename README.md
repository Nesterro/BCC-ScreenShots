# 📷 ScreenShot Studio

![ScreenShot Studio Logo](app_icon.png)

**ScreenShot Studio** — нативное десктопное приложение для Windows (.NET 10 / WPF), предназначенное для мгновенного захвата экрана в оригинальном пиксельном качестве, создания вырезок и векторных аннотаций (стрелки, выноски, рамки, текст, нумерованные шаги).

## 🌟 Основные возможности и улучшения

### 📸 Кристально чёткий захват экрана (DPI-Aware)
- **✂️ Захват рамкой (Region Snippet)**: Высокоточное выделение любой области экрана с индикатором размеров в реальных физических пикселях (`Ш × В px`), направляющими линиями и полупрозрачным затемнением невыделенной области. Без смещений и потери качества на экранах с любым масштабированием (125%, 150%, 200%).
- **📸 Поддержка нескольких мониторов**:
  - Захват основного экрана
  - Выбор любого внешнего дисплея из удобного выпадающего меню «📸 Экран ▾»
  - Захват панорамы всех мониторов сразу
- **🎯 100% резкость и чёткость**: Скриншоты сохраняются и копируются в нативном физическом разрешении без размытия текста и пикселизации.
- **📁 Импорт изображений**: Открытие PNG, JPG, BMP с диска.

### 🎨 Инструменты аннотаций
- **💬 Выноски с настраиваемым фоном (`C`)**:
  - Быстрый выбор цвета фона: ⬛ Тёмный графит (`#1E293B`), ⬜ Белый (`#FFFFFF`), 🟨 Жёлтый стикер (`#FEF08A`), 🎨 В цвет контура, 🚫 Без фона (прозрачный).
  - Палитра любых оттенков фона.
  - Автоматический подбор контрастного цвета текста для идеальной читаемости.
  - Независимое перетаскивание целевой точки-указателя и карточки с текстом.
  - Редактирование текста по двойному клику.
- **↗️ Стрелки (`A`)**: Чёткие векторные указки со строгой острой геометрией.
- **🔲 Рамки (`R`) / ⭕ Овалы (`E`)**: Выделение объектов с настраиваемой заливкой и прозрачностью.
- **🔤 Текст (`T`)**: Многострочный текст с мгновенным редактированием по месту.
- **1️⃣ Порядковые метки (`N`)**: Нумерованные кружки (`1`, `2`, `3`...) с редактированием номера/текста по двойному клику.
- **✏️ Карандаш (`P`) & 🖍️ Маркер (`H`)**: Свободное рисование и полупрозрачная подсветка.
- **↖ Перемещение & Сброс (`Esc`)**: Выбор и перемещение элементов; `Esc` для сброса инструмента.

### 📋 Управление, Масштабирование и Экспорт
- **🔍 Масштабирование холста (`Ctrl + Колесико мыши`, `Ctrl + 0`)**: Плавный зум от 20% до 400%.
- **📐 Кнопка «По размеру»**: Быстрое вписывание большого скриншота в окно приложения.
- **📋 Дублирование элементов (`Ctrl + Перетаскивание мышью`)**: Мгновенное копирование любых объектов.
- **В буфер (`Ctrl + C`)**: Копирование изображения в нативном разрешении для отправки в мессенджеры и документы.
- **Сохранить PNG (`Ctrl + S`)**: Сохранение файла на диск в исходном качестве.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + Колесико` | Масштабирование холста |
| `Ctrl + 0` | Сброс масштаба на 100% |
| `Ctrl + Drag` | Дублировать / скопировать элемент |
| `Esc` | Сброс инструмента на режим выбора («↖ Выбор») |
| `Delete` / `Backspace` | Мгновенное удаление выделенного элемента |
| `Двойной клик по тексту/выноске/метке` | Редактирование содержимого по месту |
| `Ctrl + C` | Скопировать изображение в системный буфер обмена Windows |
| `Ctrl + S` | Сохранить скриншот как PNG |
| `Ctrl + Z` | Отменить последнее действие |
| `Ctrl + Y` | Повторить / вернуть отмененное действие |
